# 小欧的 iPhone 批量水印

将本 skill 内附的已签名 Apple 快捷指令交给用户，并指导在 iPhone 上使用。所有文件随 skill 携带，无需联网下载、登录或付费。

## 向用户说明用法

1. 把对应 .shortcut 文件传到 iPhone，在文件 App 中打开，进入快捷指令的导入界面，点“添加快捷指令”。
2. 在照片 App 中多选原照片，点“分享”，选择 iPhone18Pro-Batch 或 iPhone18ProMax-Batch。
3. 首次出现照片权限提示时允许保存。处理后的 JPEG 副本保存到“最近项目”，原图保留。

也可直接打开快捷指令运行，在照片选择器中多选。分享菜单未显示时，可在分享菜单底部“编辑操作”中寻找并加入；也可在该快捷指令的详细信息中检查“在共享表单中显示”。

水印为透明底白色苹果标志和 Shot on iPhone 18 Pro / Shot on iPhone 18 Pro Max，位于照片下方居中。两个版本沿用同样的字号、标志大小和垂直位置；Max 文字较长，整体占宽相应增加。机型文字是装饰性自定义文字，不读取或验证照片实际拍摄机型。
